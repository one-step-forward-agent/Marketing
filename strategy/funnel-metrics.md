# Marketing and learning metrics

## Principle
Before product-market fit, optimize for **learning density**, not vanity traffic.

## Core dashboard

| Layer | Metric | Why it matters |
|---|---|---|
| Research | real interviews per target segment | replaces synthetic assumptions |
| Research | high-confidence problem themes | evidence quality |
| Problem | trigger frequency | whether the problem recurs |
| Problem | workaround strength | indicates existing demand/cost |
| Activation | first real case completed | user crosses from curiosity to utility |
| Value | evidence-backed output rated useful | immediate value signal |
| Retention | second real case within 14 days | pull/recurrence |
| Retention | weekly review return rate | habit potential for time feedback |
| Conversion | interview → concierge pilot | willingness to invest effort |
| Revenue | concierge/pilot → paid | willingness to pay |
| Referral | qualified referrals per activated user | problem resonance |

## Guardrail metrics

- setup minutes;
- manual correction minutes per week;
- % recommendations rejected as unsupported;
- privacy/data-access refusal rate;
- % outputs with source traceability;
- deletion/export success rate.

## Metrics intentionally deferred

CAC, ROAS, SEO traffic targets and revenue forecasts are not reliable planning inputs until a repeatable activation/retention loop exists.
