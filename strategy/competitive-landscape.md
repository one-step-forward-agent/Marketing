# Competitive alternatives — current scan

**Snapshot date:** 2026-08-31.  
This document compares jobs and positioning, not feature parity. Claims should be refreshed before external use.

| Alternative | Strongest adjacent job | What it teaches us | White-space hypothesis |
|---|---|---|---|
| Motion | automatic task prioritization, scheduling, projects and work search | users value automatic "what next" execution | connect next-step guidance to inspectable evidence/rationale rather than schedule optimization alone |
| Rize | automatic time tracking, focus metrics, dashboards | objective work telemetry is valuable when review burden is low | connect time evidence to declared goals and prior decisions instead of treating focus/activity as the endpoint |
| RescueTime | automatic activity tracking, focus goals and timesheets | long-running demand exists for retrospective time visibility | make retrospective feedback explain *priority alignment*, not only activity categories |
| Limitless | persistent memory/recall of conversations; acquired by Meta and no longer selling Pendant to new customers | "never forget" is a strong memory promise and category signal | work-specific causal context + decision lineage may be a narrower wedge than total-life memory |
| Generic LLM + notes/tasks | flexible reasoning with existing sources manually pasted by user | low switching cost and broad capability | reduce repeated prompting/context assembly while showing provenance |

## Strategic implication

The product should not attempt to out-feature a project manager, time tracker, and memory platform simultaneously. The testable wedge is the **evidence bridge** between them:

`source activity → reconstructed context → explicit decision → observed outcome/time allocation → next review`
