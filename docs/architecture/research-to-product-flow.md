# Research-to-product decision flow

```text
Real/Synthetic source
   ↓ provenance + evidence type
CustomerDevelopment
   ↓ coded episode / JTBD / switching forces
JobesToBeDone
   ↓ outcome + opportunity + evidence grade
Hypothesis
   ↓ pre-registered experiment
Observed behavior
   ↓ result + negative evidence
Confidence update / kill / split / promote
   ↓ only when evidence supports it
Product Backlog → Backend / Frontend delivery
```

## Promotion gates

1. Synthetic fixtures can test schemas and code only.
2. Real research must preserve source IDs and contradictions.
3. Opportunity score never overrides evidence grade.
4. Hypothesis confidence increases only from observed evidence, not narrative plausibility.
5. A failed experiment may delete a backlog item; backlog size is not a success metric.
6. Product implementation must keep the same lineage principle for derived AI outputs.
