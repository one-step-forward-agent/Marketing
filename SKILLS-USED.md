# Marketing skills applied

The marketing upgrade uses the operating principles from these Agent Skills:

1. **product-marketing** — establish a versioned `.agents/product-marketing.md` before downstream marketing work.
2. **customer-research** — separate research modes, extract JTBD/pains/triggers/outcomes/alternatives, score evidence confidence, and avoid invented personas/quotes.
3. **interview-to-jtbd** — keep claims traceable to source material and separate observations, inferences, assumptions, and recommendations.
4. **marketing-plan** — structure execution through acquisition, activation, retention, referral and revenue, but adapt scope to pre-PMF learning rather than fake a mature 12-month growth machine.
5. **content-strategy** — distinguish searchable vs. shareable content and map topics to buyer stage.

## Installation note

The execution container has no outbound DNS, so `npx skills add` / `git clone` cannot physically install the external repositories here. Their current `SKILL.md` files were read from the public source and applied directly. No third-party executable scripts were run.
