# Experiment register

All thresholds are pre-declared hypotheses; none have been met yet.

| ID | Experiment | JTBD | Pre-registered threshold | Kill / revise criterion |
|---|---|---|---|---|
| H009 — Explicit decision criteria matrix | Compare free-form AI advice with a criteria matrix on three ambiguous decisions. | `decision-support` | Decision completion time falls by 25% and confidence rises without lower consistency. | Kill if completion time improves by <10% or users reject weighting as burdensome. |
| H017 — Goal-vs-time weekly review | Generate synthetic weekly activity summaries and test actionability ratings. | `time-feedback` | At least 70% identify one concrete schedule change from the report. | Kill if fewer than 40% find a non-obvious actionable insight. |
| H002 — Source-linked decision history | Test a decision-history prototype with hidden/visible rationale variants. | `context-restoration` | At least 80% of participants correctly explain prior rationale after a 48h gap. | Kill if source links are ignored by >70% or recall is not better than notes. |
| H007 — Context confidence indicator | Test recap cards with and without confidence/evidence completeness indicators. | `context-restoration` | Users detect low-evidence recaps 30% more accurately without slower task completion. | Kill if confidence UI does not improve calibration or causes >20% slowdown. |
| H001 — Automatic task context recap | Prototype a recap view generated from synthetic activity history and run 5 usability sessions. | `context-restoration` | Median time-to-resume is at least 30% lower than control. | Kill if median time-to-resume improves by <10% or users cannot trace key claims. |
| H014 — Decision deadline guardrail | Test decision sessions with explicit stop rules versus open-ended exploration. | `decision-support` | Median number of repeated evidence searches falls by 30%. | Kill if users bypass the guardrail in >70% of sessions. |
| H024 — Evidence-linked coaching prompt | Compare metrics-only review with one grounded coaching question. | `time-feedback` | Action-plan completion increases by 20% without lowering perceived autonomy. | Kill if users rate prompts as intrusive in >35% of sessions. |
| H011 — Reversible decision mode | Classify sample decisions by reversibility and test suggested checkpoint plans. | `decision-support` | Time spent before reversible decisions drops 20% with no increase in regret proxy. | Kill if users misclassify high-stakes decisions or checkpoint adoption is <30%. |
| H010 — Evidence-backed recommendation | Prototype recommendation cards with source-linked arguments and counterarguments. | `decision-support` | At least 75% can identify why the recommended option won and cite supporting evidence. | Kill if explanation comprehension is <60% or recommendation acceptance becomes blind. |
| H003 — Next meaningful step suggestion | Compare manual restart versus generated next-step suggestion in timed tasks. | `context-restoration` | Median first-action latency decreases by 25% without increasing wrong actions. | Kill if wrong-action rate exceeds 10% or latency improvement is <10%. |
| H021 — Deep-work evidence window | Derive candidate deep-work windows from synthetic events and ask users to validate them. | `time-feedback` | Precision >=0.80 on user-validated focus windows. | Kill if inferred windows systematically overcount passive/idle periods. |
| H015 — Alternative generation with constraints | Collect constraints first, then compare constrained vs unconstrained alternative generation. | `decision-support` | At least 80% of generated alternatives satisfy hard constraints and top-3 relevance improves. | Kill if constraint violations exceed 10% after validation. |
| H018 — Unplanned work classification | Ask users to validate classifications over a synthetic workday timeline. | `time-feedback` | Classification precision >=0.80 for planned vs unplanned work. | Kill if manual correction exceeds 20% of events. |
| H019 — Attention fragmentation score | Compare a simple switch-rate metric against self-reported focus quality in test sessions. | `time-feedback` | Metric direction agrees with user-rated fragmentation in >=70% of sessions. | Kill if users interpret the score as productivity quality despite explanations. |
| H016 — Pre-mortem on selected option | Add a two-minute pre-mortem after selection and score discovered material risks. | `decision-support` | Participants identify at least one new material risk in 50% of applicable decisions. | Kill if the step reopens decisions in >40% without useful new risk evidence. |
| H020 — Priority drift alerts | Simulate threshold-based alerts with adjustable sensitivity. | `time-feedback` | At least 50% of alerts cause a deliberate reprioritization and false-positive complaints stay <20%. | Kill if alert dismissal exceeds 80%. |
| H005 — Context snapshot on task switch | Simulate task switches and compare automatic snapshot vs no snapshot. | `context-restoration` | Restart comprehension score improves by 20% after a 24h gap. | Kill if snapshot review adds >30 seconds without measurable comprehension gain. |
| H012 — Decision journal with outcome review | Create decision journal entries and schedule synthetic follow-up outcome reviews. | `decision-support` | At least 60% of users update one criterion after structured outcome review. | Kill if review completion is <25% after two cycles. |
| H006 — Open-loop detection | Annotate synthetic event histories and measure precision/recall of open-loop suggestions. | `context-restoration` | Precision >=0.80 and recall >=0.65 on curated evaluation cases. | Kill if precision stays below 0.65 after rule/prompt tuning. |
| H004 — Cross-source context timeline | Build a clickable timeline using synthetic events from four source types. | `context-restoration` | 70% of participants locate the relevant prior event in under 60 seconds. | Kill if fewer than 50% prefer the timeline over native search. |
| H013 — Contradiction detector | Inject contradictory evidence into synthetic histories and measure detection usefulness. | `decision-support` | Recall >=0.75 for material contradictions with precision >=0.75. | Kill if false-positive rate exceeds 25% in curated cases. |
| H008 — Selective context forgetting | Prototype pin/expire controls and run ranking tasks on long synthetic histories. | `context-restoration` | Top-5 context relevance rating improves by 15% versus unfiltered history. | Kill if controls are unused by >80% or relevance does not improve. |
| H023 — Behavioral baseline and trend | Generate four weeks of synthetic activity and test trend explanations. | `time-feedback` | Users correctly identify direction of three predefined trend changes in >=80% of cases. | Kill if baseline explanations require statistical claims unsupported by the data. |
| H022 — Meeting cost reflection | Prototype a weekly meeting contribution report with goal links. | `time-feedback` | Users identify at least one meeting to shorten/remove in 40% of weekly reviews. | Kill if goal-linking requires >30 seconds manual work per meeting. |
